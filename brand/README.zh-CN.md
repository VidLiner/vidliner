# VidLiner 品牌工具包

VidLiner 是一条以验证为先的合成训练数据生产流水线。

> **可证明的合成数据。**

品牌应让人记住一件事：VidLiner 不只是生成图像；它生成候选、验证候选、重建标签，并保留足以信任或拒绝该样本的证据。

当前版本是**图像流水线 MVP**。视频跟踪、时序生成和视频导出是规划中的能力，不能作为当前版本的宣传承诺。

## 品牌定位

| 要素 | 推荐表述 |
| --- | --- |
| 品类 | 以验证为先的合成训练数据生产流水线 |
| 核心受众 | 机器学习、计算机视觉与数据平台工程师 |
| 核心承诺 | 将已有图像转化为被接受或可解释地被拒绝的训练样本 |
| 差异点 | 标签、溯源和质量证据都是一等产物 |
| 短描述 | 以对象为中心、强制验证的合成数据增强框架 |
| 标语 | **可证明的合成数据。** |

## 传播语气

保持工程师式的表达：精确、直接、平静、以证据为先。

- 推荐：“只导出通过显式质量门槛的候选。”
- 推荐：“图像流水线 MVP；视频能力规划中。”
- 避免：“自动生成完美数据集。”
- 避免：把未接入或未验证的模型写成“已支持”。

可优先使用这些动词：**生成、验证、测量、重建、追溯、拒绝、导出**。

## 视觉系统

标记将 `V` 与验证线组合：候选必须被验证后，才成为可用数据。不要拉伸、旋转、改色、添加阴影；深色字标不要置于深色背景。
